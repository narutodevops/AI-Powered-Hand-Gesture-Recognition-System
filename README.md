# Hand Gesture Recognition System

A real-time hand gesture recognition system built with Python and computer vision. The project uses a camera to detect and track hand movements, allowing users to interact with a computer through hand gestures.

## 🚀 Features

- Real-time hand detection through a webcam
- Hand movement and gesture tracking
- Computer vision-based interaction
- Live camera feed
- Lightweight Python implementation
- Easy to run and extend with additional gestures

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- Computer Vision
